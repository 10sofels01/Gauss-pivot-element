Алгоритм решения СЛАУ вида Ax=b методом Гаусса с выбором главного элемента по всей матрице.

Программа инициализирует матрицу A по одной из 4 заданных форму, которые зависят от аргумента k. Далее читает матрицу из текстового файла, если k=0. Если k=1,2,3,4, то по формулам. Строится вектор правой части b по формуле(представлена в коде). Решается система методом Гаусса с выбором главного элемента по всей матрице. Считается норма невязки ||Ax-b|| / ||b|| и норма погрешности ||x-x_точное||. Замеряется время работы алгоритма.

main.cpp: здесь проверяются ошибки (например, размерность не может быть отрицательной, аргумент k не может быть в иных пределах и т.д.), выделяется память и вызываются остальные функции. Также здесь считается невязка и время.
matrix_io.h/matrix_io.cpp: отвечают за работу с матрицами. Заполнение по формулам, чтение из файла с проверкой и вывод на экран.
gauss_solver.h/gauss_solver.cpp: сам алгоритм. Прямой ход с поиском максимума по модулю, перестановкой строк/столбцов и обратный ход.

Для сборки используется Makefile. 
Чтобы собрать программу, в терминале нужно написать: make
Далее аргументы командной строки:
./a.out n m k [filename]
где
n — размерность матрицы (n x n).
m — сколько строк и столбцов матрицы выводить на экран.
k — номер формулы для заполнения матрицы от 1 до 4. Если k=0, то матрица читается из файла.
filename — имя файла.

Находится max_elem — максимальный по модулю элемент всей матрицы. Если он < 1e-15, то матрица считается нулевой/вырожденной. tol не фиксированный, а считается по формуле eps*n*max_elem, чтобы не было проблем с точностью, так как для каждого типа tol будет свой.

Прямой ход (k = 0…n−2). На каждом шаге:

1. Выбор ведущей строки. Среди строк i>=k берётся та, у которой row_max[i] максимален → pivot_row.
2. Выбор ведущего столбца. Ищется максимум по модулю среди j >= k → pivot_col, max_val. Если max_val < tol — подматрица нулевая, матрица нулевая/вырождена.
3. Перестановка строк k и pivot_row в A и b, и в row_max/row_arg.
4. Перестановка столбцов k и pivot_col во всех строках матрицы A. При этом меняются местами col_perm[k] и col_perm[pivot_col] (запоминаем перестановки) и во всех row_arg[i], где записан k или pivot_col, значения меняются местами, иначе кэш будет указывать на другой столбец.
5. Для i > k: factor=A[i][k]/A[k][k], A[i][k]=0, для j > k: A[i][j] -= factor*A[k][j], и b[i] -= factor*b[k]. Столбец k ниже диагонали обнулён.
6. Пересчитываются только те строки i>k, у которых row_arg[i]<=k, то есть максимум был в уже исключённом столбце. Заново ищется максимум по j>=k+1. Остальные строки не трогают.

Обратный ход:

Для i = n−1…0: sum = b[i]−Σ_{j>i} A[i][j]*y[j], проверяется, что |A[i][i]|<tol, иначе вырожденна, затем y[i]=sum/A[i][i]. Далее восстонавливаем: y[i] соответствует столбцу col_perm[i] исходной матрицы, поэтому x[col_perm[i]]=y[i]. Освобождается память.

Сложность: O(n³).

Все большие массивы, матрицы и переменные выделяются не как локальные, чтобы при больших n не было bad_alloc.
